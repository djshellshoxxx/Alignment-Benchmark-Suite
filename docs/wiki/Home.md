# Alignment Benchmark Suite Wiki

An open-source benchmark for evaluating model behaviour on structured alignment scenarios: ethical reasoning,
fairness and logical reasoning. Scenarios are JSON files; scoring is deterministic and separate from response collection.

- [Developer Guide](Developer-Guide)
- [Scenario Notes](Scenario-Notes)
- [Codebase Map](Codebase-Map)

Scenario counts on this snapshot: ethical 1,419, fairness 1,800, logical 1,302 JSON files (4,521 in total).
Contribution rules: `CONTRIBUTING.md`.
